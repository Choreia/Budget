# Choreia 予算

**https://choreia.github.io/Budget/**


研究開発予算管理表（購入物品リスト・入金管理・月次・マスタ）を置き換えるアプリです。
サーバーはありません。ブラウザから直接 Google スプレッドシートと Google ドライブを読み書きします。

- 記入したものは、会社のスプレッドシートにそのまま入ります
- 経理のマネーフォワード作業は変わりません
- やめたくなったら、いつでもスプレッドシートだけで続けられます

## ロール

| | 一般ユーザ | 課長 | 経理 |
|---|---|---|---|
| 自分が出したもの | 一覧で見える | 同じ | 同じ |
| ほかの人が出したもの | 出ない | 自分の課ぶん | 全社 |
| チェック・差し戻し | できない | できる | できる |
| 課のコスト・按分 | 見えない | 自分の課 | 全社 |
| マスタの追加・停止 | できない | できない | できる |
| 支払日の入力 | できない | できない | できる |

社長のチェックは、税込10万円以上のときだけ1段増えます。`pres` ロールの人がいなければ経理が通せます。

## 画面

1. **わたしの記入** — 自分が出したものの一覧と、記入フォーム
2. **チェックする** — 課長と経理。通す／差し戻す
3. **入金予定** — 振込期日と入金確認。期日超過を出す
4. **台帳** — 確定したものの一覧。ここでは直せない
5. **課のコスト** — 月別推移、今月の内訳、課への按分
6. **抜けているもの** — 証憑の不足、検収日の空、期日超過、税区分のずれ
7. **マスタ** — 選択肢の追加と停止、人とロール

## データの置き場所

スプレッドシートに6つのタブを作ります。

| タブ | 中身 |
|---|---|
| 購入 | 購入物品リストの置き換え |
| 入金 | 入金管理の置き換え |
| マスタ | 選択肢。`有効` を FALSE にすると新規入力に出なくなる |
| 人 | メール・名前・ロール・部門 |
| 按分 | 課への分け方。キーワードが品名に入っていると当たる |
| 履歴 | 誰がいつ何を変えたか |

会社の設定（管理者・スプレッドシートID・証憑フォルダID）は、Google ドライブの
`choreia-budget-config.json` に入ります。ほかの Choreia アプリと同じです。

証憑は Google ドライブの「Choreia 予算 証憑」フォルダの下に、`G0001_品名` の形でフォルダを作って入れます。
スプレッドシートのマクロ（CreateFolderAndInserLink）は要らなくなります。

## 証憑と締め（名波さん 2026-09-11）

| こういうとき | 要る証憑 |
|---|---|
| すべて | 請求書 か 領収書 のどちらか（必ず要る） |
| あるもの | 見積書・発注書・納品書・振込証憑も、あれば全部入れる |
| 事業ごと | 事業によって変わる。設定ファイルの `projectEvidence` で足す |

仕訳に要るのは **項目・税込金額・支払方法・証憑・インボイスNo**。インボイスNo は必須。

| | 締め |
|---|---|
| 仕入の請求書 | 毎月10日までに提出。月末締め、翌月末払い |
| 立替の領収書 | 翌月1日までに提出。月末締め、翌月25日に給与とともに精算 |

支払期限と精算日は、このルールから自動で出します。

## セットアップ

**最初のひとりだけ**が設定します。2人目からは、ログインするだけでつながります。

### 1人目（経理の方）

ログインすると設定画面が出ます。

1. 証憑を入れる Google ドライブのフォルダを指定（任意。みんなで使うなら共有フォルダ）
2. **新しく作る** を押す … 「Choreia 予算 データ」ができて、6タブと見出しが入ります
   （すでにあるシートを使うなら、URL を貼って **つなぐ**）

設定した人が **オーナー兼管理者** になります。

### 2人目から

ログインするだけです。ドライブに置かれた `choreia-budget-config.json` を見つけて、
自動で同じスプレッドシートにつながります。ほかの Choreia アプリと同じ作法です。

### ロールを割り当てる

設定タブで。

- **管理者** … メールアドレスで登録します。管理者は経理ロールになります。まだ一度もログインしていない人も先に登録できます
- **人とロール** … 課長にする人と、その担当の課を決めます。ここもログイン前に登録できます

### みんなに配る

スプレッドシートを使う人全員に編集権限で共有してください。アプリは各自の権限で読み書きします。
アプリ側で権限を絞っていても、スプレッドシートを直接開けば見えます。
運用が固まったら、スプレッドシートは閲覧のみにして、書き込みはアプリ経由だけにするのが安全です。

## デプロイ

GitHub Pages。`main` に push すると反映されます。ほかの Choreia アプリと同じです。

```bash
git push
```

Google のクライアントIDは、ほかの Choreia アプリと共通のものを使っています
（承認済みの生成元が `https://choreia.github.io` なので、この置き場所でだけ動きます）。
新しく作る必要はありません。

ページ自体に会社のデータは入りません。金額も取引先も人の名前も、すべてスプレッドシート側にあります。
スプレッドシートの ID は各自のブラウザ（localStorage）に持つので、ファイルには書きません。
検索避けに `noindex` と `robots.txt` を入れてあります。

## 書き込み役を置く（スプレッドシートを誰にも共有したくないとき）

置かない場合、アプリは「その人本人として」シートに書きます。
つまり記入する人全員にシートの編集権限が要り、シートを直接開けてしまいます。

`apps-script/Code.gs` を置くと、経理の権限で動く書き込み役がシートに書くようになります。
記入する人はシートの権限を一切持ちません。シートは総務経理のドライブに置けます。

1. スプレッドシートを開く → 拡張機能 → Apps Script
2. `apps-script/Code.gs` の中身を貼る。`ALLOWED_DOMAIN` と `FALLBACK_ADMINS` を確認する
3. デプロイ → 新しいデプロイ → 種類は **ウェブアプリ**
   - 次のユーザーとして実行： **自分**
   - アクセスできるユーザー： **組織内の全員**
4. 出てきた `https://script.google.com/.../exec` をコピー
5. アプリの設定タブ → つないでいる先 → 書き込み役 に貼って「つなぐ」

つないだあとは、スプレッドシートの共有を経理だけに絞って構いません。

証憑フォルダは別です。証憑は本人がアップロードするので、本人が書き込める場所
（M2J_ALL など）に置いたままにしてください。

書き込み役を使うと、誰が何を書けるかは画面ではなくサーバー側で決まります。

- 一般ユーザ … 自分が出したものしか読めない。出したあとは直せない
- 課長 … 自分の課のぶんを読める。チェックと差し戻しができる
- 経理 … 全部

## ローカルで動かす

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

`file://` では Google ログインが動きません。必ず http で開いてください。

項目・仕訳・証憑・締め・按分・立替・マスタ棚卸し・支払依頼の8件は回答済みで、反映しました。
支払依頼の文面は台帳の「支払依頼の文面」ボタンで出ます。

残っているもの。

- 按分は D-Base の費用を製造原価とそれ以外に分けるのが本命。分けた数字をマネーフォワードに
  部門別で入れるかは未確認
- 事業ごとの必要証憑（`projectEvidence`）は、事業が増えたときに設定ファイルへ足す
- 記入者と費用の主が違うとき（代理入力）の持ち方
- 支払依頼の Slack 自動投稿。いまは文面をコピーするところまで
